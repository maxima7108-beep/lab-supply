منصة إدارة سلاسل الإمداد بالمختبر — نسخة الجوال

الملفات (ارفعها كلها كما هي في نفس المجلد):
  index.html             المنصة نفسها
  manifest.webmanifest   تعريف التطبيق (الاسم والأيقونة)
  sw.js                  يجعل التطبيق يعمل بدون إنترنت
  icon-192.png / icon-512.png / icon-maskable-512.png   الأيقونات

خطوات الرفع على GitHub Pages (مجاناً):
 1) أنشئ حساباً في github.com
 2) اضغط + أعلى الصفحة ← New repository ← اكتب اسماً مثل lab-supply ← اختر Public ← Create repository
 3) اضغط "uploading an existing file" واسحب جميع الملفات أعلاه ← Commit changes
 4) Settings ← Pages ← Source: Deploy from a branch ← Branch: main و /(root) ← Save
 5) بعد دقيقة أو دقيقتين يظهر الرابط: https://اسم-حسابك.github.io/lab-supply/

التثبيت على الجوال:
 - أندرويد (Chrome): افتح الرابط ← القائمة ⋮ ← "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية"
 - آيفون (Safari): افتح الرابط ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية"
 - عند أول مسح يطلب الإذن للكاميرا ← اختر "سماح"

ملاحظات مهمة:
 - البيانات تُحفظ داخل الجوال نفسه ولا تُرفع إلى GitHub. الرابط يحمل البرنامج فقط.
 - كل جهاز له بياناته. لنقلها: الإعدادات ← تصدير نسخة احتياطية ← ثم استعادتها في الجهاز الآخر.
 - في الآيفون: التطبيق المثبت على الشاشة الرئيسية له بيانات منفصلة عن Safari، فاستخدم دائماً الأيقونة.
 - لتحديث المنصة لاحقاً: ارفع ملف index.html الجديد مكان القديم في نفس المستودع.
